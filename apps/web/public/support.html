Getting started

Create a tournament, add your roster, generate teams, then create a bracket. Invite others using the tournament’s invite code so they can follow results live.

Need help?

Account deletion

You can permanently delete your account from Profile in the mobile app or Account settings on the web. This also removes the tournament data you organize.
